# 🎓 考研学习计划助手

一个专为 **iPad（苹果设备）** 设计的考研学习计划助手，管理 **数学一 / 英语一 / 专业课** 三科的每日刷题量和学习时长，功能完善、离线可用、数据只存在你自己的设备上。

## ✨ 功能清单

| 模块 | 功能 |
| --- | --- |
| 📅 今日 | 考研倒计时、备考阶段提示（基础/强化/冲刺/临考）、三科每日任务卡片（题数 +1/−1/+5/+10，支持手动输入）、单科计时器、今日总进度、连续打卡天数 |
| 🍅 专注 | 番茄钟（专注/短休息/长休息可配置、自动开始休息）、选择计入哪个科目、完成提示音、今日番茄统计 |
| 📊 统计 | 近 7 天/30 天做题数柱状图、学习时长堆叠图、各科日均、累计数据、打卡日历热力图（可点开看任意一天的明细） |
| 📕 错题 | 错题本：按科目/来源/错误类型记录，待复习筛选，标记已掌握，一键删除 |
| 🏫 院校 | 一键搜索院校官网发布的招生简章/专业目录/分数线；59 所热门院校官方研招网直达（985/211/双一流标签、按地区筛选、列表内搜索）；研招网/省级教育考试院权威入口；按你的考试日期自动推算「考试信息时间轴」（电脑端体验最佳，需联网） |
| ⚙️ 设置 | 修改考试日期、各科名称/每日目标题数/目标时长、**✨一键智能规划**（按剩余天数自动推荐每天做多少题、学多久）、每日提醒、深色模式、数据导入导出（JSON 备份 / CSV 报表） |
| 📱 PWA | 添加到主屏幕后像原生 App 一样全屏使用，带图标，离线也能打开（iOS 16.4+ 支持系统通知） |

## 🚀 部署（让 iPad 能访问）

网页必须放在一个能通过 HTTPS 访问的地址，iPad 上的 Safari 才能打开并「添加到主屏幕」。任选一种免费方式：

### 方式 A：GitHub Pages（推荐，免费长期）
1. 注册/登录 [github.com](https://github.com)，新建一个仓库（如 `kaoyan`）。
2. 把本文件夹里的 `index.html`、`styles.css`、`app.js`、`manifest.webmanifest`、`sw.js`、`icons/` 全部上传到仓库（网页端直接拖进去即可）。
3. 仓库 → `Settings` → `Pages` → Source 选 `Deploy from a branch` → 分支选 `main`、目录 `/ (root)` → Save。
4. 等 1–2 分钟，会生成地址：`https://你的用户名.github.io/kaoyan/`。iPad 打开这个地址即可。

### 方式 B：Cloudflare Pages（更快）
1. 打开 [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → Pages → Upload assets。
2. 直接把整个 `kaoyan-planner` 文件夹拖进去上传，发布后得到一个 `xxx.pages.dev` 地址。

### 方式 C：Netlify Drop（最简单）
1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)，把整个文件夹拖进去，几秒后即可得到地址。

### 方式 D：自己的网站（比如 cxyonly.fans 的虚拟主机）
- 用宝塔面板 / FTP 把文件夹内容上传到网站根目录或子目录（如 `/kaoyan/`），访问 `https://你的域名/kaoyan/` 即可。**注意必须是 https**，PWA 才能工作。

## 📱 iPad 上安装（像 App 一样使用）

1. 用 **Safari**（不是微信等内置浏览器）打开部署好的网址。
2. 点右上角 **分享按钮（⬆️）** → 往下滑 → **添加到主屏幕** → 点「添加」。
3. 桌面会出现一个带「研」字图标的 **考研学习计划助手**，点击即全屏打开，跟原生 App 一样。
4. 建议在「设置」页开启每日提醒（iOS 16.4 及以上支持定时通知，需先点「开启系统通知权限」）。

## 💾 数据说明

- 所有数据只保存在 **iPad 上的 Safari 本地存储**里，不上传任何服务器，不注册账号。
- 换设备 / 怕丢数据：在「设置 → 数据管理」里 **导出备份(JSON)**，新设备上导入即可；也可以导出 CSV 用 Excel 看。
- 清除 Safari 网站数据会清空记录，**重要数据请定期导出备份**。

## ⚠️ 常见问题

- **单文件版**（`考研学习计划助手-单文件版.html`）可以 AirDrop 到 iPad 用「文件」App 直接打开，无需服务器；但部分浏览器对本地文件的数据保存有限制，**强烈建议优先使用部署 + 添加到主屏幕的方式**。
- 考试日期默认为 2025-12-20，可在「设置 → 计划设置」修改；若默认日期已过期，应用会自动顺延到下一个考研季。
- 英语一如果按「阅读篇数/单词单元」来数，把「每天目标题数」设成篇数即可，叫法不影响使用。
- 「院校」页需要联网使用（电脑上打开体验最佳）：搜索直接跳到百度/必应搜索结果；59 所热门院校提供官网直达 + 搜索兜底，若学校改版换了网址，点该行的「搜索」即可。
- 提醒：Chrome/Android 支持定时系统通知；iOS 暂不支持定时通知，应用打开时会在设定时间弹出应用内提醒。
